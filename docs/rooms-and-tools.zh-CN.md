# 房间、状态图层与排列工具

适用于 `0.2.0-beta.2`。原有绘图项目继续使用原存储；这里介绍“编辑现有卡片”。

## 房间与 HA 区域

左侧“图层”展示真实条件嵌套，“房间”提供分类视图。切换视图或更改分类不移动原生图层。

选中带 `polygon()` 裁剪的图片，点击“从裁剪创建房间”；也可点击“绘制房间”逐点点击，Enter 或双击结束，Esc 取消。新房间的基础不透明度为 0，不改变卡片外观。

右侧填写名称、HA 区域、基础颜色和不透明度（0–1）。区域只筛选控制实体候选列表，不汇总或控制区域设备。区域消失时保留原 ID。实体区域优先于设备继承区域。

在图层视图 Shift 多选，再切换房间视图并点击“将选中图层加入房间”。一个图层最多归属一个房间；已受状态效果管理的内容须先“移出状态分支”才能转移房间。

“编辑边界”后可拖顶点或区域；双击边缘增加顶点，选中顶点按 Delete 删除。至少三个不同顶点、不能自交、不能超出底图。拖动一次可一步撤销。

范围修改不会移动实体图标，也不会自动重写旧图片裁剪。若要同步某张图片，先在图层视图选中它，再选择房间并勾选“使用房间范围裁剪”；图片须为全幅、居中、宽度 100% 的简单定位，且已解锁。无法可靠转换时会提示，配置保持原值。

“删除房间，保留图层”只解除管理信息，原生填充与条件仍保留。“删除房间及其图层”需要明确选择并确认，可撤销；锁定内容受到保护。

## 独立状态效果

每个房间可添加多组效果，例如主灯、夜灯和鱼缸分别使用各自控制实体。

1. 添加状态效果，填写名称、控制实体和开启／关闭状态。多个状态使用英文逗号分隔；不能重叠，也不能包含 `unknown` 或 `unavailable`。灯光使用 `on/off`，其他设备按实际状态填写。
2. 设置开启与关闭填充颜色、不透明度；不需要的填充保持 0，关闭分支也可完全留空。
3. 点击“应用状态设置”。只有已应用的设置才会写入卡片。
4. 可将选中的图片、图标、标签或条件容器用于某个分支，也可在该分支填写图片 URL，点击“新增分支图片”。分配现有图层前先解锁；未应用设置时分配按钮不可用。

状态分支在图层原位置增加原生条件包装，已有内层条件和动作保留。选择父子节点时只包装最外层节点。原有条件与新条件必须同时满足，因此不会自动解决原配置中的冲突。

未知、不可用、实体缺失和其他未匹配状态不显示任何新开关分支，基础底图和基础填充保留。不会自动增加整层关灯遮罩。新增填充与图片默认无点击动作。

“移出状态分支”会移除生成的外层条件并保留原图层。“删除状态效果”会解除它的条件包装、移除其生成的配色填充，保留内容图片和实体。若手动修改了生成条件，请先用 YAML 检查；表单不会覆盖复杂条件。

## 对齐、分布与高亮

在图层视图 Shift 多选，打开画布上方“排列”：

- 对齐提供左、水平中心、右、顶、垂直中心、底；默认以选区范围为基准，也可指定固定的关键对象，或对齐底图画布。
- 对齐需要至少两个独立对象，画布对齐允许一个；分布需要至少三个，固定两端并使对应边缘或中心等距，不是等空隙排列。
- 使用原生元素实际尺寸；裁剪图片采用裁剪范围外接框。关联元素作为一个整体，成员等量移动，不会重复移动。未知尺寸、锁定、条件容器及复杂定位不能直接排列。
- 排列只改变相关元素的 `left/top`，一次排列可一步撤销。

选中范围显示外框、裁剪轮廓和淡色填充；锁定、临时隐藏、条件关闭或透明度为零的图层也可检查。可关闭“显示选中范围”，完整预览不显示辅助线。

精确支持百分比与像素 `polygon()`。其他裁剪形式显示浏览器支持的范围填充及完整外框，提示精确轮廓限制，禁用精确排列。复杂条件祖先布局或变换也不能用于精确排列。

滚轮在画布内以鼠标位置缩放，范围 25%–400%；中键拖动平移，“适应窗口”复位。侧栏滚轮正常滚动，拖动实体或顶点时暂不缩放。视口操作不修改配置，也不增加撤销步骤。

## 保存与回退

“下载项目”保留 v2 房间、区域、效果和图层管理信息。“导出卡片”仍是标准 `picture-elements`；仅重新导入卡片 YAML 无法恢复所有房间管理信息。

更新前可下载 v1 项目。浏览器升级前自动保留原始 v1 备份，旧版无法打开 v2。已知依赖风险和验收范围见 [验证记录](../VALIDATION.md)。
