# 统一户型工作区

适用于 `0.3.0-beta.1`。空白绘制、导入底图和导入卡片都进入同一个工作区，共用项目列表、画布、选择、属性和撤销记录。

![统一工作区](unified-workspace.png)

## 项目与起点

点击“项目”选择起点或打开已有项目。顶部可修改项目名称、切换或新增楼层。“下载项目”保存完整 v3 文档；“导出卡片”只输出当前楼层的标准 `picture-elements`。

导入已有项目文件时，如项目 ID 已存在，会另存为“导入副本”，不会覆盖当前修订。删除项目进入回收区，可恢复。浏览器自动保存项目，刷新后撤销历史重新开始。

## 房间与状态树

左侧默认按房间组织；“覆盖顺序”显示真实条件嵌套和图片叠放次序。分类不改变原生节点及其覆盖顺序。

```text
书房
  常驻图层
  开灯
    主灯图片
    开灯图标
  关灯
    关灯图标
  鱼缸开灯
    鱼缸灯光图片
  鱼缸关灯
    关灯图标
```

1. 绘制房间，或选中简单 `polygon()` 裁剪图片后选择“从裁剪创建房间”。新房间填充不透明度为零。
2. 填写名称和 HA 区域。区域仅用于设备筛选和归类建议，不自动控制设备。实体自己的区域优先于继承的设备区域；失效绑定仍保留。
3. 在覆盖顺序中 Shift 多选，然后加入房间；也可拖入房间，或勾选“建议归入此房间的图层”。一个图层只能属于一个房间。
4. 已有简单实体状态条件和 `state_image` 自动显示为状态行。状态名称可在右侧重命名。复杂条件保留在图层及 YAML 中，不能确定的模拟值不会猜测。
5. 点击状态名称模拟该状态。主灯和鱼缸可分别选择；相同实体共享模拟值。状态圆点表示条件是否满足，选中样式表示当前选择。附加条件未满足时不会强行显示。
6. 点击眼睛只改变编辑画布的临时显隐。恢复眼睛后仍受条件控制；房间眼睛恢复时保留子层隐藏设置。无关闭图片时显示“使用底图”。临时显隐不清除重做记录。
7. 点击“恢复实时状态”清除模拟。完整预览忽略临时隐藏；所有预览动作均被屏蔽，不操作设备。

选择房间、状态或具体图层，右侧只展示相应属性。新增状态效果需明确填写控制实体；未知、不可用及未匹配状态均不启用新分支。

状态下可“添加已有图层”或“新增分支图片”。单纯分类不改变条件；需要更改显示规则时会展示具体规则并确认，随后计为一次撤销。锁定图层可分类，修改规则须先解锁。已有内层条件与动作保留；附加条件可能阻止效果生效。

房间填充生成原生 SVG 图片，状态填充使用原生条件元素。关闭分支可以为空，不会自动制造全屋变暗效果。原始复杂条件始终可以通过 YAML 编辑。

## 共用绘图与选择

工具栏提供选择、实体、房间、墙、门、窗、网格与吸附工具。

- 房间：逐点点击，有跟随边线和范围预览；点击起点、Enter 或双击完成，Backspace 撤回上一点，Esc 取消。
- 房间边界：拖顶点或范围整体移动；双击边缘插入顶点，选中顶点按 Delete 删除。非法或自交范围不可提交。
- 墙：连续点击绘制，提供网格与角度吸附，Enter 完成。选择后可移动或拖端点；关联门窗随墙更新。
- 门窗：选择工具后点击墙壁放置，选择后可沿墙拖动，右侧修改位置、宽度、颜色。
- 实体：先选实体与类型，再点击画布放置。已有实体保留动作；新增灯光默认切换，其他设备默认详情。预览不会执行动作。
- 选择工具支持框选；Shift 点击多选。V 选择、M 实体、R 房间、W 墙；Ctrl+D 复制，Delete 删除，Ctrl+Z 撤销，Ctrl+Y 或 Ctrl+Shift+Z 重做。输入框内不抢占快捷键。

房间范围默认只更新辅助边界和生成填充，不移动实体，也不改旧裁剪。要同步图片，先选中图片，再选择房间并勾选“使用房间范围裁剪”；须为已解锁、居中、全幅的简单图片。

墙门窗使用独立受管理 SVG 图层。请用绘图属性修改几何；这些图层不参加实体坐标排列。不要通过祖先 YAML 改写受管理结构后继续依赖几何编辑。

## 常驻排列工具与边界

画布上方直接展示 12 个图标：左／水平中心／右／顶／垂直中心／底对齐，以及对应六种分布。悬停显示名称或不可用原因，窄窗口可换行。

对齐基准可选选区范围、关键对象、底图画布。分布至少三个对象，固定两端，按边缘或中心等距，不是等空隙。关联元素使用成员外框并集，整体移动一次。锁定、复杂定位或测量不可靠时禁用。一次排列只改变相关坐标，计一步撤销。

选中图层显示外框、裁剪轮廓和淡色填充；条件关闭、临时隐藏、锁定和全透明图层也能检查。精确支持简单百分比／像素 `polygon()`，其他裁剪保留浏览器可显示范围与外框，但不能精确排列。不分析透明像素。完整预览移除辅助标记。

画布滚轮按鼠标位置缩放 25%–400%；空格拖动或中键平移；“适应窗口”复位。侧栏保持正常滚动；拖动图形时暂停缩放。视口变化不产生内容撤销步骤。

## 迁移、备份与限制

v1/v2 卡片项目和旧绘图项目统一进入 v3 项目列表。迁移前保留旧数据，重复迁移不重复创建项目；旧 IndexedDB 不修改。旧绘图完整原文保存在 v3 文档中。

旧绘图实体外观／动作、房间高级状态规则／动作、底图变换和隐藏分类不能保证原生等价时，会阻止原生卡片导出并列出原因。“导出原始绘图备份”可下载迁移前项目、ha-floorplan YAML、SVG、PNG；它不包含迁移后的编辑。此次没有将高级旧规则自动转为新原生规则。

v3 不能由 beta.2 直接打开。更新前下载旧项目，保留 beta.2 回退版本。单独导出卡片 YAML 不保存房间分类、几何绑定、锁定与其他管理信息；继续编辑应使用完整项目文件。

[验证记录](../VALIDATION.md) 区分自动检查、HA 原生检查和用户人工验收。
